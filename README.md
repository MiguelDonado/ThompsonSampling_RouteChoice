# Thompson Sampling for Route Choice Multi Armed Bandit Problem

## Overview

The objective of this project is to investigate how Bayesian learning can be used to solve a Multi Armed Bandit Problem. In particular, the Bayesian algorithm implemented is Thompson Sampling, and the Multi Armed Bandit Problem on this case is a route choice problem.

## Features

- Route choice using Thompson Sampling 
- Integration with the SUMO traffic simulator
- Bayesian learning framework
- Python implementation for simulation and algorithm execution
- R scripts for statistical analysis and visualization

## Technologies

- Python
- R
- SUMO
- Bayesian Learning
- Thompson Sampling
